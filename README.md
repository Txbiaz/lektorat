# Lektorat

Eine Seite, auf der zwei Schreiber gegenseitig ihre Kapitel lesen und Stellen kommentieren:
https://txbiaz.github.io/lektorat/

Dieses Repo enthält nur den Code der Seite, keine Texte. Nach der Anmeldung mit einem eigenen GitHub-Token liest und
schreibt die Seite direkt in einem privaten Repo; ohne Zugriff darauf zeigt sie nichts an. Der Token bleibt im Browser
und geht nur an `api.github.com`.

Die Datei wird aus einem privaten Repo hierher kopiert (`tools/lektorat.py publish-site`); Änderungen bitte dort.
